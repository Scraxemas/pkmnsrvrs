# v0.3.4 gameplay polish report

## Movement and presentation

- Authoritative movement remains deterministic at 30 Hz.
- Rendering now interpolates player, enemy, projectile, and shadow positions using the fixed-step accumulator.
- The camera follows one interpolated ground target at full follow strength with rounded pixel scrolling, avoiding a second independent lerp.
- Creation and large coordinate changes snap instead of interpolating across invalid space.

## Animation and grounding

- `PokemonAnimationController` implements idle, walk, attack, hit, stun, evolution, and defeat priorities with timed locks.
- Walk animation playback is only changed when state/direction requires it; repeated render frames do not restart the animation.
- Direction changes preserve animation progress where Phaser supports it.
- Sprites use one stable `(0.5, 1)` origin. The renderer no longer swaps origins by facing.
- `groundOffsets.ts` contains bottom-transparent-padding measurements for every frame of every imported eight-direction PMD walk sheet.
- The sprite artwork is offset per frame while the logical position, shadow, and camera remain attached to one ground-contact point.
- Dedicated PMD attack/hit sheets are not currently imported. Those states therefore retain walk/idle artwork while applying priority and hit/telegraph feedback without disrupting movement.

## Encounter balance

- Six normalized encounter phases drive weights, spawn intervals, alive caps, ranged caps, projectile budgets, and elite eligibility.
- Opening waves contain only Caterpie and Weedle, with no ordinary ranged attackers or enemy projectiles.
- Pidgey and Butterfree gain visible windup tint, line-of-sight checks, species-specific cooldowns, and distinct projectile shapes.
- Elite status no longer turns every species into a ranged shooter.
- Fast mode uses the same normalized phase progression as the 30-minute run.

## Diagnostics and tests

The debug overlay reports animation state/key/frame, facing, simulation/previous/render positions, ground offset, shadow/camera target, interpolation alpha, chunk, encounter phase, ranged count, projectile budget, navigation rebuilds, and deterministic hash.

Vitest covers animation priority, interpolation, grounding metadata, encounter progression, projectile windup, navigation, replay determinism, and dense crowds. Playwright captures directional motion frames and verifies the camera target exactly follows the interpolated player point.

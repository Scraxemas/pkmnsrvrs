# v0.3.3 FRLG tileset integration pass

## Result

Viridian Forest now renders its core terrain from the user-supplied FireRed/LeafGreen outdoor sheet. The former 64 px generated-art terrain cells have been replaced with native 16 px source cells at a fixed 2× integer scale.

## Runtime changes

- Terrain grid changed from 64 px to 32 px world cells, increasing visual detail fourfold while keeping gameplay-space dimensions unchanged.
- Main routes remain approximately 160 px wide so survivor-style crowds can circulate.
- Dirt uses a nine-piece FRLG transition set for corners, edges, and fill.
- The pond uses a nine-piece FRLG shoreline and a rectangular authored footprint to avoid unsupported concave combinations.
- Trees and clusters are exact native metatile crops at 2× scale. Grass-coloured pixels connected to crop boundaries are keyed transparent so canopies can overlap paths and water without square background patches.
- Spawn zones now explicitly reject decoration placement, preserving shared flow-field reachability after the denser terrain conversion.

# v0.3.3 FRLG tileset integration pass

## Result

Viridian Forest now renders its core terrain from the user-supplied FireRed/LeafGreen outdoor sheet. The former 64 px generated-art terrain cells have been replaced with native 16 px source cells at a fixed 2× integer scale.

## Runtime changes

- Terrain grid changed from 64 px to 32 px world cells, increasing visual detail fourfold while keeping gameplay-space dimensions unchanged.
- Main routes remain approximately 160 px wide so survivor-style crowds can circulate.
- Dirt uses a nine-piece FRLG transition set for corners, edges, and fill.
- The pond uses a nine-piece FRLG shoreline and a rectangular authored footprint to avoid unsupported concave combinations.
- Trees use assembled FRLG metatiles at 2× scale. Each standalone tree combines its cap, crown, and trunk while skipping the sheet's repeating forest-wall rows. Grass-coloured pixels connected to the sprite boundary are keyed transparent, with two pixels of transparent padding to preserve the full silhouette.
- Spawn zones now explicitly reject decoration placement, preserving shared flow-field reachability after the denser terrain conversion.

## Tree clipping correction

The outdoor sheet contains repeating and overlapping tree parts. Rectangular crops previously included duplicate crowns or omitted the canopy cap and trunk. The extractor now assembles complete conifer and broadleaf silhouettes and adds transparent padding. Runtime anchors align the trunks, and placement leaves space between trunks across chunk boundaries.

Opaque tall-grass and flower tiles now stay in the ground layers rather than sorting over tree canopies by world Y. This removes square cutoffs beside foliage patches. A browser regression checks transparent sprite boundaries, foliage layering, and retained tree objects when crossing a streamed chunk seam. Visual checkpoints cover forest walls, the ancient tree beside tall grass, and both sides of a chunk transition.

Correction validation: 95 unit tests, 5 Chromium end-to-end tests, TypeScript checking, and the production build pass.

## Grass crop correction

Dense tall grass and scattered leaf tufts now use the complete 16×16 tuft at source cell (2, 203), keyed transparent and padded on every side. The earlier 12-row repair of cell (2, 1) left a flat lower edge and is superseded. Flowers use the complete red cluster at cell (4, 0). Browser regression checks reject tree-cap contamination. Walking bends the tufts, brushes loose blades outward, and draws a transparent foreground blade layer around Pokémon feet.
